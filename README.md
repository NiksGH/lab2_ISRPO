# Geometric Library

## Общее описание

`Geometric Library` — библиотека на Python для выполнения
основных геометрических вычислений.

Библиотека содержит функции для работы с двумя геометрическими фигурами:

- **круг** — вычисление площади и длины окружности;
- **квадрат** — вычисление площади и периметра.
