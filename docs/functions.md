# Документация функций

Данный документ содержит описание функций библиотеки `geometric_lib`, входных и выходных данных, а также примеры использования.

## 1. Функции для работы с кругом

### `area(r)`

Вычисляет площадь круга по заданному радиусу.

**Входные данные:**

| Параметр | Тип | Описание |
|---|---|---|
| `r` | `float` | Радиус круга |

**Выходные данные:**

Возвращает значение площади круга типа `float`.

**Формула:**

\[
S = \pi r^2
\]

**Пример использования:**

```python
from circle import area

result = area(5)
print(result)
```

Результат:

```text
78.53981633974483
```

---

### `perimeter(r)`

Вычисляет длину окружности по заданному радиусу.

**Входные данные:**

| Параметр | Тип | Описание |
|---|---|---|
| `r` | `float` | Радиус круга |

**Выходные данные:**

Возвращает длину окружности типа `float`.

**Формула:**

\[
P = 2\pi r
\]

**Пример использования:**

```python
from circle import perimeter

result = perimeter(5)
print(result)
```

Результат:

```text
31.41592653589793
```

---

## 2. Функции для работы с квадратом

### `area(a)`

Вычисляет площадь квадрата по длине его стороны.

**Входные данные:**

| Параметр | Тип | Описание |
|---|---|---|
| `a` | `float` | Длина стороны квадрата |

**Выходные данные:**

Возвращает значение площади квадрата типа `float`.

**Формула:**

\[
S = a^2
\]

**Пример использования:**

```python
from square import area

result = area(5)
print(result)
```

Результат:

```text
25
```

---

### `perimeter(a)`

Вычисляет периметр квадрата по длине его стороны.

**Входные данные:**

| Параметр | Тип | Описание |
|---|---|---|
| `a` | `float` | Длина стороны квадрата |

**Выходные данные:**

Возвращает значение периметра квадрата типа `float`.

**Формула:**

\[
P = 4a
\]

**Пример использования:**

```python
from square import perimeter

result = perimeter(5)
print(result)
```

Результат:

```text
20
```
